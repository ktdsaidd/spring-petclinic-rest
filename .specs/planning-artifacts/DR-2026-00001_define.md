- 변경 후: 기존 방문 수정 화면에서 담당 수의사 변경 가능
- 변경 후: 기존 방문(수의사 미지정)은 목록에서 공백/"-" 표시, 데이터 변경 없음

## 2. 요청 개요

### 2.1 요청 배경

- 현재 방문 예약에는 반려동물, 방문 날짜, 설명만 기록되고 어느 수의사가 진료하는지는 남지 않는다.
- 접수 데스크에서는 담당 수의사를 방문 설명란에 직접 적거나 별도 수기 장부로 관리하고 있다.
- 보호자가 "지난번 진료한 선생님"을 문의하면 시스템에서 확인할 수 없어 응대가 지연된다.
- 수의사별 예약 현황을 파악할 방법이 없어 진료 일정 배분이 어렵다. (단, 현황 조회 기능은 이번 SR 범위 제외 — CQ-003)

### 2.2 요청 목적

1. 방문 예약 단계에서 담당 수의사를 시스템에 기록한다.
2. 방문 내역에서 담당 수의사를 바로 확인할 수 있게 한다.
3. 설명란 수기 입력과 별도 장부 관리를 없앤다.

## 4. 상세 요구사항 정의

### 4.1 REQ-001. 방문 등록 시 담당 수의사 선택

방문 등록 화면에 담당 수의사 선택 항목을 추가한다. 선택 목록은 등록된 수의사 마스터 목록(전체)이며, 선택한 수의사는 방문 기록에 저장된다.

| 항목 | 내용 |
|---|---|
| 요구사항 ID | REQ-001 |
| 요구사항명 | 방문 등록 시 담당 수의사 선택 |
| 요구 구분 | 기능 |
| 기능ID/모듈ID | 미기재 |
| 명칭 | 방문담당수의사선택 |
| 적용 범위 | Owners > Search > 보호자 선택 > Pets and Visits > Add Visit (방문 등록 화면, New Visit) / 접수 데스크 담당자 |
| 상세 내용 | 방문 등록 화면에 담당 수의사 선택 항목을 추가한다. 선택 목록은 등록된 수의사 마스터 목록(전체)이며, 선택한 수의사는 방문 기록에 저장된다. |
| 입력 항목 | 담당 수의사 (등록된 수의사 목록 중 1명 선택, 필수) |
| 처리 조건 | 접수 데스크 담당자가 방문 등록 화면에서 방문 날짜·설명을 입력하고 방문 추가를 제출할 때 |
| 처리 결과 | 담당 수의사가 지정된 방문 기록이 저장되고, 보호자 상세의 방문 목록에 해당 수의사와 함께 표시된다. |
| 예외 사항 | 담당 수의사를 선택하지 않으면 방문 추가가 실행되지 않고 입력 화면에 미선택임이 표시된다 (필수 입력 — CQ-001 확정). |
| 검수 기준 | 조건/수행/기대결과 — (조건) 방문 등록 화면에서 방문 날짜와 설명을 입력하고 담당 수의사를 선택하지 않은 채 방문 추가를 제출한다. (수행) 시스템은 저장을 거부한다. (기대결과) 담당 수의사 미선택이 표시되고 방문이 등록되지 않는다. 수의사를 1명 선택 후 다시 제출하면 방문 목록에 선택한 수의사 이름과 함께 방문이 등록된다. |

### 4.2 REQ-002. 방문 목록의 담당 수의사 표시

반려동물별 방문 목록에 담당 수의사 이름 열을 추가하여, 방문 날짜·설명과 함께 담당 수의사를 즉시 확인할 수 있게 한다.

| 요구사항 ID | REQ-002 |

| 요구 구분 | 기능 |
| 기능ID/모듈ID | 미기재 |
| 명칭 | 방문목록수의사표시 |
| 적용 범위 | Owners > Search > 보호자 선택 > Pets and Visits (반려동물별 방문 목록, 방문 등록 화면 하위 "Previous Visits" 포함) / 접수 데스크 담당자 |
| 상세 내용 | 반려동물별 방문 목록에 담당 수의사 이름 열을 추가하여, 방문 날짜·설명과 함께 담당 수의사를 즉시 확인할 수 있게 한다. |
| 입력 항목 | 해당 없음 (표시 요구) |
| 처리 조건 | 접수 데스크 담당자가 보호자 상세의 방문 목록(또는 방문 등록 화면 하위 이전 방문 목록)을 조회할 때 |
| 처리 결과 | 각 방문 행에 담당 수의사 이름이 표시되어, 보호자가 "지난번 진료한 선생님" 문의 시 시스템에서 즉시 확인 가능하다. |
| 예외 사항 | 이전에 등록된 방문으로 담당 수의사가 지정되지 않은 건은 수의사 칸을 공백/"-"로 표시하며, 기존 데이터의 소급 입력·변경은 하지 않는다 (CQ-004 확정). |
| 검수 기준 | 조건/수행/기대결과 — (조건) 담당 수의사가 지정된 방문과 미지정(기존) 방문이 혼재한 반려동물의 방문 목록을 조회한다. (수행) 목록이 렌더링된다. (기대결과) 지정된 방문은 수의사 이름이 표시되고, 미지정 방문은 수의사 칸이 공백/"-"로 표시되며 다른 정보(날짜·설명)는 그대로 유지된다. |

### 4.3 REQ-003. 기존 방문의 담당 수의사 변경

이미 등록된 방문의 수정 화면에 담당 수의사 선택 항목을 제공하여, 등록된 수의사 목록 중 다른 수의사로 변경(또는 미지정 상태에서 지정)할 수 있게 한다.

| 요구 구분 | 기능 |

| 상세 내용 | 이미 등록된 방문의 수정 화면에 담당 수의사 선택 항목을 제공하여, 등록된 수의사 목록 중 다른 수의사로 변경(또는 미지정 상태에서 지정)할 수 있게 한다. |
